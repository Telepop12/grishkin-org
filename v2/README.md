# AI Innovation Lab — v2

Локальный прототип концепции «Живая лаборатория».

Откройте `index.html` в современном браузере. Сборка и зависимости не нужны.

- `index.html` — контент и SVG-схема;
- `styles.css` — дизайн и адаптивность;
- `pipeline-layout.js` — геометрия агентов на активных дугах;
- `app.js` — четыре сценария, чат, темы, RU/EN-локализация и интерактивность;
- `tests/agent-placement.test.js` — проверка расположения агентов.

Подробная история решений и улучшений: [CHANGELOG.md](CHANGELOG.md).
