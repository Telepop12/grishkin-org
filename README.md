# AI Innovation Lab — сайт-визитка

Одностраничный сайт лаборатории **AI Innovation Lab** (Вячеслав Гришкин).
Self-contained: весь CSS / JS / логотип внутри `index.html` — без сборки, без зависимостей, без бэкенда.

**Живой сайт:** https://grishkin.org (Cloudflare Pages)

## Как обновлять
- **Мелочи** (текст, дата, ссылка): править `index.html` прямо на GitHub — кнопка ✏️ → Commit. Через ~минуту изменение на сайте.
- **Локально**: открыть `index.html` в браузере для предпросмотра → `git commit` → `git push`.
- **Картинки**: класть файлы в `img/`, вставлять `<img src="img/имя.png">`.

Любой push в ветку `main` → Cloudflare Pages пересобирает и деплоит автоматически. Откат — через историю деплоев в дашборде или `git revert`.

## Что внутри
Pure HTML/CSS/JS: интерактивная canvas-схема «три потока — один интерфейс», чат-окно с симуляцией диалогов агентов, inline-SVG логотип, тёмная/светлая тема. Внешних зависимостей и трекеров нет.

## Безопасность
Статика за сетью Cloudflare (авто-HTTPS, DDoS-защита). Поверхность атаки минимальна. Правила: 2FA на GitHub и Cloudflare; никаких секретов (IP, токены, пароли, hostname'ы) в репозитории — контент обезличен намеренно.
