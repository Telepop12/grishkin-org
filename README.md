# AI Innovation Lab — сайт

Сайт лаборатории **AI Innovation Lab** (Вячеслав Гришкин).
Чистые HTML/CSS/JS: без сборки, без зависимостей, без бэкенда.

**Живой сайт:** https://grishkin.org

## Структура

```
public/            ← всё, что раздаётся наружу
  index.html         главная: hero, AI Fabric / AI Systems, Live Lab,
                     системы, принципы, журнал, публикации
  styles.css         общий дизайн обеих страниц (темы, адаптив)
  app.js             сценарии Live Lab, чат, темы, RU/EN
  pipeline-layout.js геометрия агентов на дугах SVG-схемы
  fabric/            страница /fabric — инженерный контур
    index.html         архитектура, принципы, граф выполнения задачи
    fabric.js          анимация графа, RU/EN, темы
  img/               картинки
tests/             проверки геометрии и SVG-путей (Node, без зависимостей)
wrangler.jsonc     конфиг Cloudflare (assets из public/)
```

Тема и язык хранятся в `localStorage` (`ailab-theme`, `ailab-lang`) и переживают переход между страницами. Обе страницы понимают `?theme=dark|light` и `?lang=ru|en` в ссылке.

## Как обновлять

- **Мелочи** (текст, дата, ссылка): править файл в `public/` прямо на GitHub — кнопка ✏️ → Commit.
- **Локально**: открыть `public/index.html` в браузере для предпросмотра → `git commit` → `git push`.
- **Картинки**: класть в `public/img/`, вставлять `<img src="img/имя.png">`.

Любой push в `main` → Cloudflare пересобирает и деплоит сам, примерно за минуту. Откат — `git revert` или история деплоев в дашборде.

⚠️ Правки вносить только в `public/` — именно эта папка раздаётся наружу.

## Безопасность

Статика за сетью Cloudflare (авто-HTTPS, DDoS-защита). Поверхность атаки минимальна. Правила: 2FA на GitHub и Cloudflare; никаких секретов (IP, токены, пароли, hostname'ы) в репозитории — контент обезличен намеренно.
